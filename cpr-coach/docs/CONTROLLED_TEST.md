# Controlled test

Use three students: one rescuer, one phone holder, and one counter with a stopwatch. Set the phone side-on to the rescuer, use a firm cushion, and make sure the room is well lit. Choose **Practise** or **Emergency** and record which mode; never call 112.

For each run, the rescuer says “START” out loud, pushes for 20 seconds, stops for 5 seconds, pushes for 20 seconds, then stops. The counter counts compressions out loud during each push block and records the count and the stopwatch’s exact elapsed seconds for each block. Do three runs: at the metronome pace, deliberately slow (about 90/min), and deliberately fast (about 130/min). Then do one additional 20-second block with deliberately bent elbows; count it and mark it **bent**. Keep the phone and cushion setup the same.
