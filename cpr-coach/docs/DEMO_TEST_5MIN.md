# Five-minute live demo test

Use a firm cushion only; never practise on a person. Keep the phone side-on and steady except during step 5. Never place a call to 112. For each step, mark Pass or Fail and note what appeared; these are expected behaviours to check, not measured results.

| Step | Action and expected behaviour | Pass / fail | What was seen |
|---|---|---|---|
| 1 | Push with straight arms and shoulders over hands for 30 s: teal skeleton and rate. | | |
| 2 | Deliberately bend elbows for 20 s: amber within about 2 s and “Straighten arms.” | | |
| 3 | Straighten arms: teal returns within about 2 s. | | |
| 4 | Lean back until shoulders are not over hands for 20 s, then correct posture: amber while leaning, teal after fixing. | | |
| 5 | Turn phone towards rescuer's front: “Turn the phone side-on”; no posture judgement. Return phone to side-on. | | |
| 6 | Stop pushing for 5 s, then restart: “Detecting,” then rate. | | |
| 7 | Tap Emergency once: one-word instruction and “Call 112” visible. Do not call. Hold to stop; check summary. | | |
