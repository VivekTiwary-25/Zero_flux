## App-wide
- MainActivity is the launcher, opening straight to Home. Ask for CAMERA, RECORD_AUDIO and POST_NOTIFICATIONS once at app open. A denied permission must never crash: Practise with no camera permission shows frame_no_person.
- Manifest: keep the existing permissions and uses-feature. Keep lab.LabActivity and lab.LabAudioService declared, but the activity is no longer a launcher and has exported=false. Add MainActivity. Add `<service android:name=".audio.MetronomeService" android:exported="false" android:foregroundServiceType="mediaPlayback" />`. Add `android:configChanges="orientation|screenSize|keyboardHidden|screenLayout"` on MainActivity so a rotation never restarts a session.
- Language: AppSettings.language. Provide LocalStrings from AssetStrings.load, and reload on change. Language applies to screen text, clips and recognition.
- Orientation: portrait everywhere, except landscape while the Practise camera is showing. Use requestedOrientation, restored on leaving. Keep the screen on in Practise and Emergency.
- System back: from anywhere goes to Home, ending what was running. Do not let it silently leave a metronome running.

## Practise (PractiseHost)
- First Practise shows WalkthroughScreen, then sets walkthroughSeen. Later ones go straight to the camera, with a small "?" that reopens the walkthrough.
- Camera: PoseCameraView feeding PoseEngine.submit. PoseEngine results arrive on another thread: post each to the main thread and call PractiseSession.onFrame there. A LaunchedEffect calls session.tick about every 250 ms using SystemClock.uptimeMillis(), which is the same clock PoseEngine uses. All session calls stay on the main thread. Show CameraOverlay with session.ui.
- PractiseSession takes a SessionAudio: adapt AudioEngine to it. Remember the last key played, for "repeat". Start calls session.start(now). Pause and Stop call togglePause and stop. Start the PoseEngine trace with startTrace(File(getExternalFilesDir(null), "traces")) when a session starts, and stopTrace when it ends: this is how accuracy gets measured.
- When session.scorecard becomes non-null show ScorecardScreen. "Swap roles" starts a brand new session at framing, Home goes Home. Close PoseEngine and release AudioEngine when leaving.

## Emergency (EmergencyHost)
- Opens straight in with no setup. Call 112 opens Intent(ACTION_DIAL, Uri.parse("tel:112")) and NEVER ACTION_CALL. Nothing in this app may ever place a call by itself.
- Start compressions: MetronomeService.start. Run EmergencySequence.start through the engine's play with onDone chained so clips play one after another, then tick about once a second, queuing what is due. A clip must never cut off another.
- stepKey for the screen: em_call to em_step_call, em_hands to em_step_hands, em_push to em_step_push, keeping the last of these shown.
- The metronome and voice must keep going while the dialer covers the app. Do not stop them in onPause or onStop.
- Stop (hold) calls MetronomeService.stop and goes Home.
- The helper camera is cut from this build: leave showHelperCameraButton at its default of false.

## Mic and voice commands (VoiceRouter, one HandsFreeController for the app)
- Every screen's MicButton uses one shared state. Tap calls toggle(current language code). Stop listening when the language changes.
- While state is LISTENING call setVoiceMuted(true) on whichever AudioEngine is live, and false otherwise. The metronome keeps playing.
- onTranscript runs CommandMatcher with loadCommandTable. Home: EMERGENCY, PRACTISE, plus allowLanguages true. Practise camera: START, STOP, REPEAT. Emergency: CALL, STOP. Scorecard and walkthrough: nothing.
- START calls session.start, which already refuses unless framing is ready. STOP calls session.stop in Practise, and goes Home in Emergency. REPEAT replays the last clip. CALL opens the dialer as above and never calls.
- If speech.hasModel(language) is false, do not crash. The mic simply hears nothing useful.
