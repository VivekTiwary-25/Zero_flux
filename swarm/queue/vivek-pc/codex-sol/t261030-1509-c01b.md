    @Composable fun HomeScreen(language: AppLanguage, micState: MicState, onEmergency: () -> Unit, onPractise: () -> Unit, onLanguageChosen: (AppLanguage) -> Unit, onMicTap: () -> Unit, modifier: Modifier = Modifier)
    @Composable fun MicButton(state: MicState, onTap: () -> Unit, modifier: Modifier = Modifier)

Home is an unequal two-block bento: a huge coral clay Emergency button filling most of the top half, a smaller Practise clay button below. Emergency gets the app's richest press animation (deeper sink, layered shadow, a single restrained pulse on press) built on ClayButton. A glass language chip in a corner shows language.nativeName and opens a glass picker sheet of all ten AppLanguage values, each large enough to tap; choosing one calls onLanguageChosen and closes it. Picker open/close is state inside HomeScreen, not a new screen. MicButton sits on Home within thumb reach.
MicButton: at least 56dp. OFF is quiet, LOADING shows a small progress ring with mic_loading as content description, LISTENING uses teal with one soft ring that moves only while listening. Coral is for Emergency only; amber is not used here.
Nothing animates while the screen is at rest. Respect reduced motion: read Settings.Global.ANIMATOR_DURATION_SCALE and skip pulses when it is 0. Touch targets at least 48dp. Long Indian-language strings must still fit, so allow wrapping and use no fixed-height text boxes.
Done when both composables exist with exactly these signatures and contain no business logic.
