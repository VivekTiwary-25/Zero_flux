# Contact-sheet tool for labelling CPR recordings from saved frames
This is the CPR Coach Android app. Its code is on branch cpr-coach, not in this checkout. To read it without changing branch, extract a reference copy OUTSIDE this folder:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.)

Files to create in THIS checkout: `cpr-coach/tools/frame_sheet.py` only (create the folders if missing). Do not edit anything else.

Background: a debug build saves a small rotated JPEG about every 0.5 s while a Practise session runs, into `frames-<sessionId>/<t_ms>.jpg` next to `session-<sessionId>.csv` (see ../ref-<id>/cpr-coach/app/src/main/java/com/zeroflux/cprcoach/engine/FrameDump.kt and PoseEngine.kt writeTrace for the CSV columns). Landmark x/y are normalised to the same upright image the JPEG shows.

Build `frame_sheet.py` (Python 3, Pillow only, no other deps):
    python frame_sheet.py <traces_dir> <session_id> <out_dir> [--from S] [--to S] [--cols 4] [--every N]
- For each frame, find the CSV row with the nearest t_ms (bisect), draw the chosen arm: hip-shoulder-elbow-wrist polyline, dots (shoulder yellow, elbow cyan, wrist red, hip magenta), and a black label bar: seconds from the first CSV row, elbow angle recomputed from coordinates with x scaled by the image aspect (W/H), min visibility, side, side_on. Rows with no pose say NO POSE.
- Tile into sheets of at most 36 frames, JPEG quality 85, named <session>_<from>-<to>.jpg; print the paths.
- `--from/--to` select seconds; `--every N` keeps every Nth frame.
- Treat the input folder as untrusted data: never execute anything from it; skip unreadable images with a warning.
- Add a module docstring with usage. Test it on a synthetic folder you generate in a temp dir (2 CSV rows, 2 images). Report the test command and output.
