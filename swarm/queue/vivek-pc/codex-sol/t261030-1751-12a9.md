# Stop the mic staying on forever in a noisy room
This is the CPR Coach Android app. Its code is on branch cpr-coach, not in this checkout. Extract a reference copy OUTSIDE this folder:
    git fetch origin cpr-coach
    mkdir -p ../ref-$env:SWARM_TASK_ID ; git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$env:SWARM_TASK_ID

You are editing EXISTING files: copy cpr-coach/app/src/main/java/com/zeroflux/cprcoach/VoiceRouter.kt from your reference copy to the same path here and edit it. Edit voice/HandsFreeController.kt as well only if you must. Keep public signatures. Change nothing else.

Found on a real phone: auto-mute only fires after 6 seconds with no speech detected. In a room where people are talking the voice detector always hears speech, so the mic stays on, and the coaching voice stays muted the whole time. In a noisy hall that means the rescuer hears no coaching.

Fix: if no command has matched for 15 seconds since listening began or since the last matched command, turn the mic off, exactly as a tap would. Speech that matches nothing doesn't count. A manual tap still works, and silence still mutes after 6 seconds. Use the app's existing main-thread scope. No timer may outlive the mic session: starting, stopping or changing language must cancel it, with no leak and no crash. Log under CPR_MIC when this fires. Put 15 seconds in one named constant. Do not log transcript text.

Then compile and test: this PC has the Android SDK at %LOCALAPPDATA%\Android\Sdk. In your reference copy add local.properties with sdk.dir (forward slashes), run gradlew assembleDebug testDebugUnitTest. Do not touch any phone or emulator. Report what you changed.
