Build on the noisy-room fix if it isn't on the branch yet: `git fetch origin refs/heads/task/t261030-1751-12a9` and copy VoiceRouter.kt from FETCH_HEAD. Review finding: when a screen is left, VoiceRouter only clears its command callback (VoiceRouter.kt:79-86) while the mic keeps recording, with nothing able to use what it hears and the coaching voice possibly muted. Fix: when the screen that owns the commands goes away, stop listening, so the mic turns off and voice unmutes. A screen change must always leave the mic button showing the true state. Also check for a mic session starting late: a LOADING session finishing after the screen has gone must not begin recording (HandsFreeController.kt:174-185).
