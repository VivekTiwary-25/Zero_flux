# Trace timeline: what the app would show and say for any pulled recording
This is the CPR Coach Android app (Kotlin, Compose). Its code is on branch cpr-coach, not in this checkout. Extract a reference copy OUTSIDE this folder without changing branch:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(PowerShell: $env:SWARM_TASK_ID.) To run its unit tests: inside ../ref-<id>/cpr-coach run ./gradlew testDebugUnitTest (gradlew.bat on Windows; set ANDROID_HOME or local.properties sdk.dir if Gradle asks). Write your deliverables in THIS checkout at the paths given; edit nothing else. Docs: plain short sentences.

Deliverable: cpr-coach/app/src/test/java/com/zeroflux/cprcoach/engine/TraceTimelineTest.kt (new file only).
A JUnit test that is skipped unless the system property or env var CPR_TRACE points at a session-<id>.csv (columns t_ms, wrist_signal, elbow_deg, min_vis, ..., side, shoulder_x..hip_vis, side_on). It replays the trace through a real PractiseSession (engine/PractiseSession.kt) with a fake SessionAudio that records play(key): feed frames as PoseFrame WITH ArmLandmarks (aspect 4/3; nearRight from the side column R/L), get framing ready, start, tick through the countdown, then tick every 250 ms on the same clock, never before the last frame (shift times so the recording starts when the session goes live). Print one line per second: t, tracking, rate, posture good/issue, elbow median, and any phrase played in that second; then a summary of phrases with times. Write the same to app/build/trace-timeline.txt. Show in the report the output for tools/testdata/real-cph2467-15.csv. Look at PauseVoiceReplayTest.kt and CoachReplayTest.kt on cpr-coach for how others drive the session. Usage line at the top of the file: gradlew.bat testDebugUnitTest --tests '*TraceTimelineTest*' -DCPR_TRACE=... (make sure the property reaches the test JVM: if it doesn't, use the env var and say so).
