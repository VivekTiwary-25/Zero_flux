# Natural, clinical voice lines for English, Hindi and Kannada
This is the CPR Coach Android app (Kotlin, Jetpack Compose). Its code is on branch cpr-coach, not in this checkout. To read it, without changing branch, extract a reference copy OUTSIDE this folder:

    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.) Read ../ref-<id>/cpr-coach/docs/SPEC.md (sections 1, 3 and 5 are the product and design rules), plus ui/Theme.kt and ui/Contract.kt under app/src/main/java/com/zeroflux/cprcoach/. Use their colours, ClayButton, GlassPanel, AppLanguage, MicState, CameraUiState and LocalStrings. Do not change those files or copy them here.
Only create the NEW files listed below, at those paths under cpr-coach/ in this folder. Nothing else may appear in this folder. Files written by other workers are referenced by the signatures given here, so do not write them yourself.
All visible text goes through LocalStrings.current.get("key") using keys in assets/strings/en.json. If you need a new key, do not edit en.json: list the key and its English in your report.
No invented numbers anywhere: no sample rates, scores or demo values in production code.
You do not need to compile if this machine has no Android SDK, and do not install one. Be careful with imports, because the boss compiles and reviews afterwards. Say in your report whether you compiled.
You are editing EXISTING files, an exception to "only new files". Copy each named file from your reference copy to the same path here and edit it there. Change no others. Run no adb and touch no phone.

Files: tools/clipgen/phrases_en.json, phrases_hi.json, phrases_kn.json, and the regenerated clips under app/src/main/assets/clips/en, hi and kn, plus tools/clipgen/TRANSLATION_NOTES.md.
The team found current Hindi and Kannada lines robotic, overly literal, and some sexually suggestive out of context, such as "दबाते रहो" and "दबाते रहें" with no object. Rewrite every line so it sounds natural, professional, clinical and unambiguous. Always name the CHEST where pushing is meant, for example "छाती दबाते रहें" (and the Kannada equivalent, ಎದೆ), never a bare verb like press or push. Use polite forms, short sentences, everyday words a frightened bystander knows. Keep the same keys and meaning: countdown, push_faster, slow_down, elbows_straight, keep_going, good, session_done, em_call, em_hands, em_push, em_swap, em_aed, em_continue, and any others present. slow_down must not read as press softer. Numbers are spelled out for the TTS. English also: "Push faster" becomes e.g. "Push the chest faster". Any line that could be misheard or read as inappropriate is a defect.
Also add two new keys in all three languages for later: shoulders_over_hands ("Bring your shoulders over your hands") and turn_phone is NOT spoken, so skip that one.
Then regenerate the clips with tools/clipgen/generate_clips.py, models read only under D:\projects\sih\iTantra\app\src\main\assets. Keep format and folder layout. List each old and new line in TRANSLATION_NOTES.md, and flag each one as a draft needing a native speaker's ear. Run tools/clipgen/check_clips.py and report the result. Do not touch any phone.
