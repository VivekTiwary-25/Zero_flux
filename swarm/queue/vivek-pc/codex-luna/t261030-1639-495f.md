    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.) You do not need to compile if this machine has no Android SDK, and do not install one. Be careful with imports, because the boss compiles and reviews afterwards. Say in your report whether you compiled.

New file only: cpr-coach/docs/ACCURACY_TEST.md. Plain exact steps for two students to measure the app's rate accuracy on a real phone. It must work on a cushion or pillow, or on a home-made mannequin if that is ready, with the same steps, and the surface used gets recorded.
The holder stands at the rescuer's side with the phone sideways. Three runs of about 60 seconds, aiming for about 90, 110 and 130 per minute. The app's metronome is NOT the guide, because the rescuer following it would flatter the result: use a separate phone's metronome or none. A third person, or a video, counts compressions by hand against a stopwatch.
Say how to start a session in the app, and how to pull the trace with adb from the app's external files folder under traces/, then run: python cpr-coach/tools/analyze_trace.py <csv> --count N --seconds S. Results go in docs/MEASUREMENTS.md. Read tools/analyze_trace.py and docs/MEASUREMENTS.md so that the steps match them. No results or expected accuracy figures: nothing has been measured yet.
