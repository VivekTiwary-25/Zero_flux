# Run the real app on an emulator and report what happens
This is the CPR Coach Android app (Kotlin, Jetpack Compose). Its code is on branch cpr-coach, not in this checkout. To read it, without changing branch, extract a reference copy OUTSIDE this folder:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.) Read ../ref-<id>/cpr-coach/docs/SPEC.md (sections 1, 3 and 5 are the product and design rules), plus ui/Theme.kt and ui/Contract.kt under app/src/main/java/com/zeroflux/cprcoach/. Use their colours, ClayButton, GlassPanel, AppLanguage, MicState, CameraUiState and LocalStrings. Do not change those files or copy them here.
Only create the NEW files listed below, at those paths under cpr-coach/ in this folder. Nothing else may appear in this folder. Files written by other workers are referenced by the signatures given here, so do not write them yourself.
All visible text goes through LocalStrings.current.get("key") using keys in assets/strings/en.json. If you need a new key, do not edit en.json: list the key and its English in your report.
No invented numbers anywhere: no sample rates, scores or demo values in production code.
You do not need to compile if this machine has no Android SDK, and do not install one. Be careful with imports, because the boss compiles and reviews afterwards. Say in your report whether you compiled.

New file only: cpr-coach/docs/EMULATOR_RUN.md. Change no code. Build from your reference copy with local.properties sdk.dir set; this PC has the SDK at %LOCALAPPDATA%\Android\Sdk. The Whisper files are not in git: copy tiny.en-* from D:\projects\sih\iTantra\app\src\main\assets into your reference copy's app/src/main/assets, reading only from there.
Use only an emulator, and pass -s emulator-XXXX on EVERY adb command. A real phone may be attached and is in human use: NEVER install on, start on, or send anything to a real phone. List AVDs with the emulator tool. If none exists, or none can run, create none and say so, and stop.
The APK is arm64 only. If the emulator cannot install it, you may change abiFilters in your reference copy only, and say so in the report. Native speech libraries may then be missing, so note it if the mic fails for that reason: that would not be a bug in the app.
Walk through: Home, language picker (choose Hindi and see the text change), Practise walkthrough cards, the camera screen and its framing hints, back to Home, Emergency, Start compressions, the Call 112 button opening the dialer with 112 filled in. STOP there: never press the call button in the dialer. Then long-press Stop. Also rotate during a session if possible. Save screenshots in a folder outside this checkout, and describe each in the report.
Report: for each step what you saw, every FATAL EXCEPTION or native crash in logcat with the first lines of its stack, and any layout or text problem. Say plainly that an emulator proves nothing about pose accuracy, audio or real phones. If the emulator is too unstable, say so rather than guessing. Shut the emulator down at the end.
