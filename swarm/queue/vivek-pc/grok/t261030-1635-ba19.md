New files: cpr-coach/tools/clipgen/check_clips.py and cpr-coach/docs/CLIP_CHECK.md.
Transcribe every clip in the reference copy's app/src/main/assets/clips/<code>/ with the recogniser for that language and compare to the text in tools/clipgen/phrases_<code>.json, using character error rate after removing punctuation. Do en and hi first, as they are required for tonight, then kn, then the rest as time allows. Also check that each clip is mono 16-bit, has no clipping, is not silent, and is within 0.2 to 8 seconds.
CLIP_CHECK.md: a table of language, key, expected text, heard text, error rate, flagged yes/no, flagging error rate above 0.3. State at the top that this is a machine check of what the voice says and does NOT replace a person listening, and do not change CLIP_STATUS.md. The numbers in this file are real measurements from your run, so never estimate them.
