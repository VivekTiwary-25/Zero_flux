    class MetronomeService : Service() {
        companion object {
            fun start(context: Context, languageCode: String)
            fun stop(context: Context)
            val engine: StateFlow<AudioEngine?>
        }
    }
Foreground service of type mediaPlayback, low-importance ongoing notification titled "CPR metronome". On start it creates one AudioEngine, sets the language, starts the metronome at 110 and publishes it in engine. On stop it releases the engine and sets engine to null. Starting twice is harmless. The manifest is handled by the boss: state the exact service line it needs in your report. If notifications are denied, it must still run.
