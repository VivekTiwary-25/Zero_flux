Another worker is writing this class in the same package, so use it but do not write it:
    class SpeechEngine(context: Context) { fun transcribe(samples: FloatArray, sampleRate: Int, languageCode: String): String; fun preload(languageCode: String); fun release() }
MicState comes from ui/Contract.kt.

    class HandsFreeController(context: Context, private val speech: SpeechEngine, private val scope: CoroutineScope, private val silenceTimeoutMs: Long = 6_000) {
        val state: StateFlow<MicState>
        var onTranscript: ((String) -> Unit)?   // called on the main thread with each non-blank utterance
        fun toggle(languageCode: String)        // OFF to LOADING to LISTENING; a tap while on turns it off
        fun stop()
        fun release()
    }
Behaviour: toggle on shows LOADING while speech.preload runs on a background dispatcher, then LISTENING. A tap during LOADING cancels it. Record 16 kHz mono 16-bit PCM from MediaRecorder.AudioSource.VOICE_COMMUNICATION, and enable android.media.audiofx.AcousticEchoCanceler when isAvailable, because a metronome is playing from the speaker. Feed Silero VAD in its window size. Each finished speech segment goes to speech.transcribe on one background worker, so recognition never blocks reading the mic. Trust the VAD only: after silenceTimeoutMs with no speech, turn OFF by itself and release the mic. Anything that fails (mic silenced during a phone call, AudioRecord init fails, no permission, no model) turns it OFF, logs under tag CPR_MIC, and never crashes. Assume the permission may be missing and catch SecurityException.
Important: while on a phone call Android may give apps silence, which simply looks like no speech. That is fine, it auto-mutes.
Do not do command matching here. Do not play any audio.
