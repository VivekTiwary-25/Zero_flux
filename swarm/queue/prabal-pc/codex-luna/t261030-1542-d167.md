# One last update of this PC's main swarm checkout
The running swarm service was started from a normal checkout of this repo on this PC, in a different folder from the one you are in. Update that checkout once. This one task is allowed to work outside your folder, but only as described here.

1. Find the checkout. It is the folder containing `swarm/swarm.py` in the command line of the running swarm listener process.
   Linux: `ps -eo args | grep "[s]warm.py"`. Windows PowerShell: `Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -match 'swarm.py' } | ForEach-Object { $_.CommandLine }`.
   Ignore any path under `.swarm/repo`. If the only path is under `.swarm/repo`, this PC is already updated: say so and stop.
2. In that folder run `git status --short --branch`.
3. If it is on branch main, run `git pull --ff-only origin main`. If it is on another branch, or the pull refuses because of local changes, do NOT stash, reset, checkout, delete or commit anything. Other people use this checkout. Just report what you saw.
4. Run `git log --oneline -1` there.

Do not restart any process, and do not edit any file except your report. Your report must say: the folder, the branch, whether the pull worked, and the last commit line.
