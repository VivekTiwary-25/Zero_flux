New file only: cpr-coach/app/src/test/java/com/zeroflux/cprcoach/AndroidHazardsTest.kt. JUnit 4. Background: a regex using the inline flag (?U) passed all desktop tests and crashed the app at startup on Android, because Android's regex engine rejects it. The test scans all Kotlin under src/main/java and fails on things that work on the JVM but not on Android: the inline regex flags (?U) and (?d), Pattern.UNICODE_CHARACTER_CLASS, \\p{IsAlphabetic} style classes, and any use of java.lang.management, java.awt or javax.swing. Keep it simple, with file:line in the failure message. It must pass on the branch now; if it doesn't, leave it failing and name the file in your report. In your report also list any other JVM-versus-Android differences you notice by reading src/main/java, without changing code.
