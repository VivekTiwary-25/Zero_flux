# Translate screen text and coaching phrases into 9 Indian languages
This is the CPR Coach Android app (Kotlin, Jetpack Compose). Its code is on branch cpr-coach, not in this checkout. To read it, without changing branch, extract a reference copy OUTSIDE this folder:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.) Read ../ref-<id>/cpr-coach/docs/SPEC.md (sections 1, 3 and 5 are the product and design rules), plus ui/Theme.kt and ui/Contract.kt under app/src/main/java/com/zeroflux/cprcoach/. Use their colours, ClayButton, GlassPanel, AppLanguage, MicState, CameraUiState and LocalStrings. Do not change those files or copy them here.
Only create the NEW files listed below, at those paths under cpr-coach/ in this folder. Nothing else may appear in this folder. Files written by other workers are referenced by the signatures given here, so do not write them yourself.
All visible text goes through LocalStrings.current.get("key") using keys in assets/strings/en.json. If you need a new key, do not edit en.json: list the key and its English in your report.
No invented numbers anywhere: no sample rates, scores or demo values in production code.
You do not need to compile if this machine has no Android SDK, and do not install one. Be careful with imports, because the boss compiles and reviews afterwards. Say in your report whether you compiled.

Languages: hi Hindi, kn Kannada, ta Tamil, te Telugu, ml Malayalam, mr Marathi, gu Gujarati, bn Bengali, or Odia.
Sources: cpr-coach/app/src/main/assets/strings/en.json and cpr-coach/tools/clipgen/phrases_en.json (on the branch, see your reference copy).
New files: cpr-coach/app/src/main/assets/strings/<code>.json for each of the 9, cpr-coach/tools/clipgen/phrases_<code>.json for each of the 9, and cpr-coach/tools/clipgen/TRANSLATION_NOTES.md.
Every file has exactly the same keys as its English source. UTF-8, 2-space indent, LF, native script only.
Phrases file: add one more key, lang_name, the language's own name in its own script. Do not add lang_name to strings files.
These are for a CPR practice app, spoken by a coach to someone doing compressions, so use short, natural, spoken everyday words that ordinary people use, not formal or Sanskritised dictionary terms. They are read aloud by a simple speech engine, so phrases files must have NO digits at all: spell out numbers in words, including 112 as one-one-two said digit by digit. Use only simple punctuation (comma and full stop or danda). Keep AED as the spoken letters written in that script. Keep them as short as the English.
Screen strings: keep 112 and 100-120 as digits, and keep them short since they sit on buttons. Coach-style wording, plain imperative.
TRANSLATION_NOTES.md: a table, per language, of any phrase you were unsure about and why, plus any you consider risky for medical meaning. All of these are drafts until a native speaker checks them, so do not claim otherwise.
Check: run a small script confirming each file parses, the key sets match, and phrases files contain no digits. Report the result.
