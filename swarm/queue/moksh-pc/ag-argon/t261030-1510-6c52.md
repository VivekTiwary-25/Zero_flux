New file: cpr-coach/app/src/main/assets/commands.json. Speech recognition returns plain text in the current language (English from Whisper, the others from IndicConformer in native script) and we do simple keyword matching.
Shape: { "<code>": { "emergency": [...], "practise": [...], "start": [...], "stop": [...], "repeat": [...], "call": [...], "languages": { "en": [...], "hi": [...], "kn": [...], "ta": [...], "te": [...], "ml": [...], "mr": [...], "gu": [...], "bn": [...], "or": [...] } } } for all ten codes: en hi kn ta te ml mr gu bn or.
Each list holds lower-case words or short phrases a person would really say in that language, 2 to 5 entries, including the common English loanword written in that script when people really use it (for example start spoken in Kannada, written in Kannada script). "languages" holds what a speaker of that language would call each language. Native script except for en. No duplicates across emergency, practise, start, stop, repeat and call within a language, because matching must not be ambiguous.
Check with a small script that it parses, that all codes and keys exist, and that there are no duplicates. Report the result, and flag anything unsure. These are drafts until a native speaker checks them.
