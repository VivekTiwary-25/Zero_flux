    data class ArmLandmarks(val shoulderX: Float, val shoulderY: Float, val shoulderVis: Float, val elbowX: Float, val elbowY: Float, val elbowVis: Float, val wristX: Float, val wristY: Float, val wristVis: Float, val hipX: Float, val hipY: Float, val hipVis: Float)
    data class FramingAdvice(val ready: Boolean, val hintKey: String?)
    class FramingAdvisor(private val minVisibility: Float = 0.5f, private val holdMs: Long = 1_000) { fun update(nearArm: ArmLandmarks?, timeMs: Long): FramingAdvice }

Coordinates are normalised 0 to 1 in the image. hintKey is one of the string keys below; ready is true only when no hint applies, held for holdMs. Any problem resets the hold immediately, but a hint must stay for at least 500 ms so the text does not flicker. In priority order:
- nearArm null: frame_no_person
- wrist not visible or within 0.03 of an image edge: frame_arm_out
- hip not visible or within 0.03 of an edge: frame_hip_out
- shoulder or elbow not visible: frame_side_on
- shoulder-to-hip distance above 0.6 of the image height: frame_move_back
Tests with JUnit 4 and a fake clock for each hint, the hold, the immediate reset, and no flicker.
