# Diagnose why two swarm workers failed to start on this PC
Read only: change nothing except your report, restart nothing, log in to nothing. Run these and paste their output, unedited, in code blocks in your report:

    command -v omp; omp --version
    ps -eo pid,etimes,args | grep "[s]warm.py"
    tail -n 60 ~/.swarm/state/listener.log
    tail -n 20 ~/.swarm/state/watchdog.log
    grep -n "cannot start\|no_agent\|blocked" ~/.swarm/state/*.log | tail -n 20
    ls ~/.swarm/work 2>/dev/null
    git -C ~/.swarm/repo log -1 --format='%h %s'
    git -C ~/.swarm/repo status --short | head -n 20
    df -h ~/.swarm | tail -n 1

Mask any line that contains a token or key. The report may be longer than the usual limit.
