# Phone model setup script
This is the CPR Coach Android app (Kotlin, Jetpack Compose). Its code is on branch cpr-coach, not in this checkout. To read it, without changing branch, extract a reference copy OUTSIDE this folder:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.) Read ../ref-<id>/cpr-coach/docs/SPEC.md (sections 1, 3 and 5 are the product and design rules), plus ui/Theme.kt and ui/Contract.kt under app/src/main/java/com/zeroflux/cprcoach/. Use their colours, ClayButton, GlassPanel, AppLanguage, MicState, CameraUiState and LocalStrings. Do not change those files or copy them here.
Only create the NEW files listed below, at those paths under cpr-coach/ in this folder. Nothing else may appear in this folder. Files written by other workers are referenced by the signatures given here, so do not write them yourself.
All visible text goes through LocalStrings.current.get("key") using keys in assets/strings/en.json. If you need a new key, do not edit en.json: list the key and its English in your report.
No invented numbers anywhere: no sample rates, scores or demo values in production code.
You do not need to compile if this machine has no Android SDK, and do not install one. Be careful with imports, because the boss compiles and reviews afterwards. Say in your report whether you compiled.

New file: cpr-coach/tools/push-models.ps1 (Windows PowerShell 5.1). It cannot be run on your machine, so review it carefully by reading.
Parameters: -Serial <adb serial, optional; if omitted use the only attached device, and stop with a clear message if there are none or several>, -ModelDir, default D:\projects\sih\iTantra\model-staging\indicconformer.
Steps: check the ModelDir has shared\encoder.weights.bin, kn.onnx and languages\kn\tokens.txt, else stop. Check com.zeroflux.cprcoach is installed (adb shell pm list packages), else tell the user to install it first. Check about 1.5 GB free on /data/local/tmp. Then run:
    adb push <ModelDir> /data/local/tmp/indicconformer
    adb shell "run-as com.zeroflux.cprcoach sh -c 'mkdir -p files && rm -rf files/indicconformer && cp -r /data/local/tmp/indicconformer files/indicconformer'"
    adb shell "rm -rf /data/local/tmp/indicconformer"
    adb shell "run-as com.zeroflux.cprcoach ls -lR files/indicconformer"
Find adb on PATH, else at %LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe. Stop on any failed step using $LASTEXITCODE, not $?, and do not redirect adb stderr with 2>&1. Print what it is doing in plain language. Also add -CopyWhisper, which copies tiny.en-encoder.int8.onnx, tiny.en-decoder.int8.onnx and tiny.en-tokens.txt from D:\projects\sih\iTantra\app\src\main\assets to the repo's cpr-coach\app\src\main\assets (found relative to the script), for use before a build.
