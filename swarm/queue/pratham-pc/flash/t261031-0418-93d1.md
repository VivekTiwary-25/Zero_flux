# Short note: what the recordings 13-15 contain
This is the CPR Coach Android app (Kotlin, Compose). Its code is on branch cpr-coach, not in this checkout. Extract a reference copy OUTSIDE this folder without changing branch:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(PowerShell: $env:SWARM_TASK_ID.) To run its unit tests: inside ../ref-<id>/cpr-coach run ./gradlew testDebugUnitTest (gradlew.bat on Windows; set ANDROID_HOME or local.properties sdk.dir if Gradle asks). Write your deliverables in THIS checkout at the paths given; edit nothing else. Docs: plain short sentences.

Deliverable: cpr-coach/docs/RECORDINGS_13_15.md only.
From tools/testdata/labels.csv and the file headers of tools/testdata/real-cph2467-13.csv, -14.csv, -15.csv (ref copy): duration, frame count, share of rows with a pose, median latency_ms and frame gap (from columns latency_ms and consecutive t_ms), and the labelled segments. One short table per recording plus two lines of context: 13 is a different rescuer (checked shirt), 14 has a sit-up rest at about 24.7-33.5 s and the phone dropped at 33.5 s, 15 is the labelled straight/bent/lean run. Stdlib Python; put the command in the doc.
