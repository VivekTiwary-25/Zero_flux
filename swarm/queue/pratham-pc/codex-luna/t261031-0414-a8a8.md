# Synthetic check: lean forward and lean back are judged symmetrically
This is the CPR Coach Android app (Kotlin, Compose). Its code is on branch cpr-coach, not in this checkout. Extract a reference copy OUTSIDE this folder without changing branch:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(PowerShell: $env:SWARM_TASK_ID.) To run its unit tests: inside ../ref-<id>/cpr-coach run ./gradlew testDebugUnitTest (gradlew.bat on Windows; set ANDROID_HOME or local.properties sdk.dir if Gradle asks). Write your deliverables in THIS checkout at the paths given; edit nothing else. Docs: plain short sentences.

Deliverable: cpr-coach/app/src/test/java/com/zeroflux/cprcoach/engine/LeanDirectionTest.kt (new file only).
engine/PostureJudge.kt learns a per-session baseline (first ~6 s of good side-on frames: median elbow and median signed shoulder-wrist offset) and flags SHOULDERS_NOT_OVER_HANDS when the offset deviates from that baseline by more than a margin (read the code for the current numbers). No recording has a lean FORWARD (shoulders past the hands); only lean back was recorded. Build synthetic side-on frames (ArmLandmarks with shoulder, elbow, wrist, hip; aspect 4/3; 30 fps; small realistic noise and a 110/min vertical wrist motion) for: 8 s straight (shoulder directly above wrist), then 6 s lean back (shoulder moved toward the hips by ~0.25-0.35 arm length), 6 s straight, 6 s lean forward (shoulder moved past the wrist by the same amount), 6 s straight; and the same with the rescuer facing the other way (mirror x). Feed them to PostureJudge (and also through LiveAnalyzer if easy). Assert both lean directions are flagged within about 3 s and cleared within about 3 s of returning, in both facings, and that the straight stretches are quiet. If a direction or facing fails, keep the test but mark that case @Ignore with the exact reason and report the numbers (time to flag, share flagged). Run the full suite in the ref copy.
