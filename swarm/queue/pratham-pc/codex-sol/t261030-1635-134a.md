# Crash-proofing pass: no permissions, no models
This is the CPR Coach Android app (Kotlin, Jetpack Compose). Its code is on branch cpr-coach, not in this checkout. To read it, without changing branch, extract a reference copy OUTSIDE this folder:
    git fetch origin cpr-coach
    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.) Read ../ref-<id>/cpr-coach/docs/SPEC.md (sections 1, 3 and 5 are the product and design rules), plus ui/Theme.kt and ui/Contract.kt under app/src/main/java/com/zeroflux/cprcoach/. Use their colours, ClayButton, GlassPanel, AppLanguage, MicState, CameraUiState and LocalStrings. Do not change those files or copy them here.
Only create the NEW files listed below, at those paths under cpr-coach/ in this folder. Nothing else may appear in this folder. Files written by other workers are referenced by the signatures given here, so do not write them yourself.
All visible text goes through LocalStrings.current.get("key") using keys in assets/strings/en.json. If you need a new key, do not edit en.json: list the key and its English in your report.
No invented numbers anywhere: no sample rates, scores or demo values in production code.
You do not need to compile if this machine has no Android SDK, and do not install one. Be careful with imports, because the boss compiles and reviews afterwards. Say in your report whether you compiled.
You are improving an EXISTING file, which is an exception to "only new files". Copy that one file from your reference copy to the same path in this folder, then edit it there. Keep its public function signature exactly, because other code calls it. Change no other file. Your report must list what you changed.
A full build must be on a phone tonight, so make small, safe changes only.

You may edit only these existing files: voice/SpeechRecognizerManager.kt, voice/SpeechEngine.kt, voice/HandsFreeController.kt, ui/PoseCameraView.kt, and audio/MetronomeService.kt. Read engine/PoseEngine.kt and audio/AudioEngine.kt too, and report problems in them without editing them.
Trace these by reading the code, as there is no phone: camera permission denied; mic permission denied, or revoked while listening; IndicConformer files missing, or a language with no model; tiny.en assets missing from the APK; silero_vad.onnx missing; pose model fails to load on GPU and CPU; no back camera; camera in use by another app; notification permission denied; clip missing. The rule is: the app never crashes, and it never pretends something works. Native sherpa-onnx code can abort the process on a bad path, so check files exist before handing paths to it.
Fix what is unsafe in the allowed files. PoseCameraView must not crash when the camera can't bind: catch the failure and log it under CPR_CAM, and the overlay will simply stay on frame_no_person. Report a table: situation, what happens now, fixed or not.
