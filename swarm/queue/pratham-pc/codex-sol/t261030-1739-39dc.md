    mkdir -p ../ref-$SWARM_TASK_ID && git archive FETCH_HEAD cpr-coach | tar -x -C ../ref-$SWARM_TASK_ID
(On Windows PowerShell use $env:SWARM_TASK_ID.) No invented numbers anywhere: no sample rates, scores or demo values in production code.

You are editing EXISTING files, which is an exception to "only new files". Copy each named file from your reference copy to the same path here and edit it there. Keep public signatures unless told otherwise. Change no others. Small safe changes only. Do not touch any phone or emulator.

File: MainActivity.kt, and AppRoot.kt or PractiseHost.kt only if needed. Spec section 3: ask for all permissions at app open. Today it asks on first launch only. Ask at each open for any still missing, without looping on a permanent denial.
